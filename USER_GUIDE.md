# Quick start

Close Revit and install the matching package. Start Revit and enable **Revit MCP Switch** for model tools.

Open **Codex Chat > Codex-vindue**, select **Codex-app**, then choose **Vis i Revit**. Use the round refresh button if the app window is missing. A maximized or minimized app is restored automatically before placement.

Status reports placement or pause; it does not prove that the app's content rendered. Click the app's own composer to use Codex. **Vis igen** resumes a minimized/maximized source. **Frigør** restores its original desktop placement and show state. The **⋯** menu contains launch, preview, recovery and technical details.

The window-placement integration is experimental. Native menus/dialogs can open separately. The **Tekstchat** tab retains the limited shared text client.
