# Install Codex for Revit

See [README](README.md#install) for installation and [Danish setup](docs/codex-setup-da.md) for the Revit 2026 workflow.

Use a Codex release built from this fork. The upstream binary does not contain this fork's chat integration. For an existing installation, close Revit and pass `-Force` to the installer; a backup is created automatically.

Install Codex and sign in on each computer. No account credentials are shared through the repository.
